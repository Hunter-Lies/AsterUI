# AsterUI UI Examples

## hello-overlay

Smallest bridge handshake and host-driven value.

## interactive-menu

Tabs, switches, pointer input, and event emission.

## notification

Compact event-driven notification surface.

## demo-ui

Complete reference UI with player status and actions, vehicle controls, GTA map
waypoint and destination teleport, time and weather controls, and Chinese/English
language switching. It is launched by the included demo plugin.

## vite-starter

Localhost Vite setup for HMR development.

The examples focus on UI authoring. Plugin/native implementation is outside
the UI tutorial scope.
