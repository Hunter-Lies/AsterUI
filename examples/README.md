# AsterUI UI Examples

## hello-overlay

Smallest bridge handshake and host-driven value.

## interactive-menu

Tabs, switches, pointer input, and event emission.

## notification

Compact event-driven notification surface.

## demo-ui

Complete reference UI with player status, player actions, GTA map waypoint
detection, and waypoint teleport controls. It is launched by the included demo
consumer.

## vite-starter

Localhost Vite setup for HMR development.

The examples focus on UI authoring. Consumer/native implementation is outside
the UI tutorial scope.
