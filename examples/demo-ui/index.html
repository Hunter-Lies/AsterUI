说明：插件如何工作

插件负责加载 AsterUI 页面、接收页面事件并执行游戏功能。AsterUI 只负责浏览器、共享帧、输入和事件桥接，页面不直接执行游戏代码。

01 · HTML用户操作
02 · BridgeJSON 事件
03 · ASI插件逻辑
04 · GTA VNative 执行

支持范围

GTA V PC 传承版、Windows x64、单机剧情模式。不支持 Enhanced、FiveM、RedM 或 GTA Online。发布包不包含游戏和 ScriptHookV 文件。

显示或关闭界面F5
关闭界面Esc
界面打开时锁定游戏控制AUTO

插件边界

AsterUI.Demo.asi 是公开 Demo 插件，仅用于验证 UI 通讯、输入和状态同步。它不是完整修改器，也不替代菜单、任务或载具插件。实际项目的业务逻辑应放在自己的 ASI 或 RPH 插件中。

页面全部资源均为本地文件，不使用 CDN、远程字体或网络请求。
