# Contributors / 贡献者

[中文](#中文) | [English](#english)

## 中文

贡献者头像由已合并到 `main` 分支的提交记录自动生成。

- 提交代码或文档并被合并的人计入贡献者。
- 仅提出问题、建议或测试反馈的人可以在 Pull Request 或 Release Notes 中单独致谢。
- 仓库维护权限与贡献次数不是同一个概念。

## English

Contributor avatars are generated from commits merged into `main`.

- A person who contributes merged code or documentation is listed as a contributor.
- Issue reporters, reviewers, and testers may be credited separately in pull requests or release notes.
- Repository maintenance permission is not the same thing as contribution count.
